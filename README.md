We provide three distinct datasets with dependency annotations:
• Silver Data: Automatically generated UD-to-SCL parses for all available mantras of the
Ṛgveda-Saṃhitā.
• Gold-Annotated Data: A set of 347 mantras from the first Maṇḍala, that is manually
corrected and annotated.
• Gold-Validated Data: A high-precision subset of 102 mantras, further validated through
consultation with senior Vedic scholars.
